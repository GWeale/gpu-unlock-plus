created with the built-in image-generation tool. It is not a photograph of a
particular board, a diagram of NVIDIA internals, or a performance result.

The original upstream banner remains in `banner.svg` for the archived upstream
README. Source and research credits remain in the project documentation.

## Generation brief

Use case: ads-marketing.
Asset type: a professional open-source GitHub repository banner for a Linux GPU kernel project called Tensor Reclaim, replacing a plain text-and-chip SVG.
Create one exceptional wide panoramic banner, approximately 3:1 aspect ratio, suitable for a README at 1280–1600 pixels wide. Editorial hardware illustration with precise typography and a restrained, premium engineering aesthetic. Dark graphite and brushed titanium, with warm amber signal traces. A detailed, plausible abstract GPU silicon package on the right; its geometric tensor array is illuminated in a controlled pattern, with a subtle open circuit motif suggesting recovered access. This is a conceptual illustration, not an actual product photograph or technical diagram. Strong composition, crisp material detail, clean negative space.
Place the exact title "Tensor Reclaim" on the left in large, beautiful, highly legible modern sans-serif type. Beneath it, the exact smaller subtitle "RTX 20 / 30 · Linux kernel engineering". The title must remain clear at README/mobile sizes. Keep all text and the central visual within generous safe margins. Make this feel like a serious systems project with an original identity.
No performance numbers, no speedup claims, no charts, no NVIDIA logo, no padlock icon, no hacker imagery, no gaming RGB rainbow, no purple neon, no extra words, no watermark. Opaque background.
