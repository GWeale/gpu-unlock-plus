# Latchloom artwork

[latchloom-banner.png](latchloom-banner.png) is an original conceptual brand
illustration generated for this project with the built-in image-generation tool.
The selected PNG is used without visual edits.

The identity uses a woven geometric mark, cobalt and vermilion on warm paper,
and an oversized lowercase wordmark. The mark suggests controlled continuity;
it is not a GPU diagram, hardware photograph, or performance result.

The upstream `banner.svg` is retained only for the archived upstream README.
Code and research attribution remain in the project documentation.

## Generation brief

Use case: logo-brand.
Asset type: original identity banner for an independent open-source Linux systems project named Latchloom.
Create a polished wide panoramic GitHub README banner, approximately 3:1, with an entirely graphic, editorial identity. Warm ivory paper background, oversized black typography, flat ultramarine/cobalt blue shapes, and a single restrained vermilion accent. Think contemporary printed design with confident negative space and a subtle clean paper texture.
Invent an original abstract woven monogram from two broad, squared ribbon paths that interlock with a deliberate open gap. It may suggest two letter L shapes and controlled continuity, but must not resemble an existing company logo, a chip, a circuit diagram, or a lock. The mark should be visually simple and recognizable at small size. Use a distinctive asymmetric poster composition with the geometric mark toward the upper-left and the wordmark large across the lower/right portion, not a conventional left-text/right-product layout.
Render the exact word "latchloom" in very large, immaculate, lowercase black grotesk type. Render only one smaller subtitle, exactly "Linux GPU unlock & recovery". Typography must be crisp, correctly spelled and readable at mobile README size, with generous safe margins around all lettering. Make the image feel designed as a unified identity, not a stock technology ad.
Flat graphic shapes and print design, no photorealism and no 3D. No hardware, GPU dies, circuit boards, circuit traces, metal, locks, keys, flames, neon, gradients, glows, dark background, gaming imagery, NVIDIA branding, performance numbers, speedup promises, watermarks, or extra words. Opaque background.
